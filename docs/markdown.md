**Markdown** es un lenguaje de marcado ligero creado en 2004 por John Gruber y Aaron Swartz. Su objetivo es permitir escribir texto con formato usando caracteres sencillos de texto plano, de modo que sea fácil de leer tal como está escrito y fácil de convertir a **HTML** (y a otros formatos como PDF, DOCX o diapositivas).

## Cómo funciona

En lugar de escribir etiquetas complejas como `<h1>Título</h1>` o `<strong>negrita</strong>`, usas símbolos intuitivos:

* **Encabezados:** `#`, `##`, `###` al inicio de una línea.
* **Énfasis:** `**negrita**` y `*cursiva*` o `_cursiva_`.
* **Listas:** `-` o `*` para listas sin orden, y `1.`, `2.` para listas numeradas.
* **Enlaces e imágenes:** `[texto](https://ejemplo.com)` y `![texto alternativo](ruta/imagen.png)`.
* **Código:** comillas simples ``código`` en línea o triples ````` para bloques de código.
* **Citas:** `>` al principio de una línea.

## Por qué se usa tanto

* **Legibilidad directa:** el texto sin renderizar sigue siendo limpio y comprensible en cualquier editor de texto.
* **Portabilidad:** al ser texto plano, funciona en cualquier sistema operativo, repositorio o editor sin depender de formatos propietarios.
* **Ecosistema amplio:** es el estándar de facto para documentación técnica (como README en GitHub y GitLab), notas personales (Obsidian, Joplin), generadores de sitios estáticos, foros y chats con IA.

## Variantes y limitaciones

El Markdown original tenía pequeñas ambigüedades en ciertos casos borde, por lo que surgieron especificaciones más estrictas y ampliadas como **CommonMark** y **GitHub Flavored Markdown (GFM)**, que añaden elementos útiles como tablas, listas de tareas y tachado. Para maquetaciones complejas o diseños tipográficos muy precisos, suele quedarse corto frente a HTML/CSS o LaTeX.
